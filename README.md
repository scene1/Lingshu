# 灵枢 / Lingshu

Lingshu is a native Electron desktop app for AI routing and OpenClaw management.

## Highlights

- Native Electron desktop window
- Built-in `server-v2.js` backend
- Internal backend port `3105`
- CC Switch routed model exposure
- App shell branding: `Lingshu`
- macOS app name: `灵枢`

## Development

```bash
npm install
npm run dev
```

## Packaging

```bash
npm run electron:build:mac
npm run electron:build:win
```
