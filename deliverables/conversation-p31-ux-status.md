# 灵枢对话体验 P3.1 实施状态

更新日期：2026-08-21

## 已完成

- 复制改为 Electron 主进程剪贴板写入，网页保留 Clipboard API 和选区复制降级。
- 消息全文、文档预览和来源片段统一使用同一复制链路。
- 普通知识检索默认排除灵枢自己生成的 AI 对话归档；用户明确询问历史对话时才会召回。
- 相关性改为查询词覆盖率、标题命中、标签/标题命中组合计算，并过滤低于门槛的来源。
- 长回答超过 1200 字或 28 行时默认折叠，保留完整 Markdown DOM，支持展开和收起。
- 对话步骤协议增加 `startedAt` / `finishedAt` / `durationMs`。
- 执行轨迹显示每个模块的实时或完成耗时，并显示整轮总耗时。
- 已移除对话顶部伪进度条和消息底部全局加载圆点。

## 检索边界

- 当前是本地词法召回后的规则重排，不是 embedding/cross-encoder 语义重排。
- OpenKB 来源仍使用 OpenKB 返回的语义分数；Obsidian/Vault 使用本次新的校准规则。
- 旧会话的历史步骤没有时间字段，界面显示 `--`；新任务开始记录真实耗时。
