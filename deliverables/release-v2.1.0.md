# 灵枢 V2.1.0

V2.1.0 将外部连接和自动化运行从配置页面推进到可验证、可控制的实际闭环。

## 本次更新

### 外部渠道

- 渠道配置改为独立 API，不再由前端读取并整份覆盖主配置。
- 密钥字段支持掩码回写，前端和错误响应不会返回真实凭证。
- 飞书、企业微信/微信、钉钉、QQ Bot、Telegram 接入真实平台鉴权测试。
- 连接状态来自最近一次真实鉴权，不再把“已启用”等同于“已连接”。

### GitHub 集成

- 连接测试从主页可达升级为 GitHub API 账号鉴权。
- 支持读取 Token 有权访问的仓库并同步到常用仓库。
- Git 服务地址和 API 地址执行同源约束，防止 Token 被发送到未授权主机。
- 仓库只在用户明确操作时读取，不会自动克隆或修改代码。

### 远程实例

- 支持 HTTP/HTTPS Runtime 健康检查、Bearer Token 和 1-30 秒超时设置。
- 支持可选的远程重启 API 与日志 API。
- 展示最近连接时间、响应延迟和远程版本。
- 禁止非 HTTP 协议、URL 内嵌账号密码和自动重定向；Token 始终掩码返回。

### Workflow 运行控制

- 每次执行生成独立 Run ID，关闭调试抽屉不会中断后台任务。
- 支持暂停、恢复、取消和跳过当前节点。
- 支持结束后单节点重试，以及串行流程从指定节点继续运行。
- 调试抽屉持续展示当前节点、节点状态、输入摘要、输出和耗时。
- 保留旧 `/api/workflows/:id/run` 同步接口，现有 Automation 调用继续兼容。

## 当前边界

- 外部渠道本次完成配置隔离和真实鉴权；公网回调地址、平台后台事件订阅和入站消息队列仍需按部署环境配置。
- GitHub 首批支持账号鉴权和仓库发现；Issue、Pull Request、Release 与 Webhook 触发将在后续小版本继续扩展。
- 远程实例首批支持受控 HTTP API；SSH 和 WebSocket 不在本次范围内。
- Workflow 当前节点执行器仍沿用现有模拟/基础执行器；Agent、Skill、Tool 的统一生产执行器继续作为后续增强。

## 发布说明

正式 Release 仍要求 macOS Developer ID + notarization 和 Windows Authenticode 凭证全部可用。缺少签名凭证时发布流水线会在构建前失败，不会生成未签名正式安装包。
