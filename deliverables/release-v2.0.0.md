# 灵枢 V2.0

灵枢 2.0 聚焦对话质量、知识检索、受控学习和桌面端可用性，完成了从对话界面到运行时、评测与治理的系统升级。

## 主要更新

- 对话运行时升级为真实 Agent Loop，支持工具调用结果回填、多轮继续生成、停止和超时控制。
- 支持 OpenAI-compatible、DeepSeek 与 Anthropic 的流式响应和完整工具消息回放。
- 对话界面增加步骤时间线、模块耗时、长内容折叠、稳定复制、来源卡片和工具执行结果。
- 知识检索增加查询清洗、会话归档降权、embedding 召回和 cross-encoder 语义重排。
- OpenKB 作为可选 Sidecar 接入，支持诊断、缓存、失败降级与来源可观测。
- 新增模型绑定和诊断入口，可分别绑定主模型、评审模型、embedding 模型和 reranker 模型。
- 新增策略 Diff、分类评测对比、灰度 cohort 分析、独立评审模型与人工标注队列。
- 候选策略继续采用“生成候选、自动评测、人工批准、灰度发布、自动回滚”的受控流程。
- 加强空值、重复请求、并发、权限、超时、异常处理和敏感信息脱敏。
- 重整应用导航，将智能体、技能、模型和连接合并为“智能体与模型”，将工具、渠道和流程合并为“工具与自动化”。
