# 灵枢对话模块 P0 实施状态

更新时间：2026-08-21

## 已完成

- Conversation Runtime v2 使用真实 Agent Loop，最多 6 轮，工具结果会回填模型继续生成。
- OpenAI-compatible、DeepSeek 和 Anthropic SSE 工具参数分片可聚合；空流和非 SSE 降级均有明确处理。
- 高风险 Skill 一律进入审批暂停状态；用户批准后恢复执行，拒绝后将结构化结果回填模型。
- App 对话界面显示等待审批、批准执行、拒绝、已拒绝和工具结果状态。
- 生成步骤只保留运行时真实事件：接收请求、上下文组装、模型调用、工具、审批和结果。
- 上下文改为 token 预算管理：默认输入上限 32K，预留输出 4K，保留近期消息并压缩旧消息。
- 建立 10 类 60 条质量基线，覆盖指令遵循、连贯性、事实边界、结构化输出、工具选择、安全审批、异常恢复、引用、长上下文和回答质量。
- 修复空 `message/reason` 被错误替换成“请求处理失败”的问题。
- 已构建并安装到 `/Applications/灵枢.app`，旧版备份为 `/Applications/灵枢.app.backup-p0-20260821`。

## 已验证

- `npm test`：25/25 通过。
- `npm run verify`：TypeScript、Vite 生产构建和后端 bundle 通过。
- DeepSeek 实际 SSE：源码后端和已安装 App 均返回预期内容。
- 已安装包内包含审批 API 与 App 审批控件；3005 健康检查通过。
- OpenAI-compatible/DeepSeek/Anthropic 工具参数分片、审批暂停恢复、上下文压缩均有自动化测试。

## P0 尚未完成的外部验证

- 未对 60 条基线执行完整付费模型评测；数据集和运行器已就绪，需要指定模型后显式运行。
- Anthropic HTTP 当前没有可见已启用模型，因此只完成协议夹具测试，没有真实 Anthropic API 工具循环记录。
- 未执行“外部模型读取本地知识后再工具回填”的实测，因为这会把本地检索内容发送给第三方模型，需要单独明确授权。

## P1 建议

- 给 60 条基线增加人工或评审模型 rubric 分数，并按模型、版本、Prompt 保存趋势报告。
- 增加可恢复的会话级长期记忆，区分用户事实、任务决定、临时上下文和模型推断。
- OpenKB 从可选 sidecar 升级为可观测的检索链路，加入命中率、引用定位、降级和缓存指标。
- 增加工具级速率限制、审批审计页和按权限分组的永久策略。
- 增加真实 Anthropic、DeepSeek 与至少一个 OpenAI-compatible 网关的夜间协议回归。
